# Portfolio Images

This folder contains all images used in the portfolio. Please replace the placeholder files with your actual images.

## Required Images

### Profile Photo
- **File**: `profile.jpg`
- **Description**: Your professional profile photo
- **Requirements**: 
  - Square aspect ratio (e.g., 800x800px or 1000x1000px)
  - High quality, clear face
  - Professional appearance
  - Will be displayed in a circular frame with glow effects

### Project Screenshots

1. **Legal AI Assistant**
   - **File**: `legal-ai.jpg`
   - **Description**: Screenshot of your Legal AI project
   - **Requirements**: Landscape aspect ratio (16:9 recommended)

2. **Formula 1 Race Intelligence Agent**
   - **File**: `f1.jpg`
   - **Description**: Screenshot of your F1 project
   - **Requirements**: Landscape aspect ratio (16:9 recommended)

3. **HavenPath**
   - **File**: `havenpath.jpg`
   - **Description**: Screenshot of your HavenPath project
   - **Requirements**: Landscape aspect ratio (16:9 recommended)

## How to Add Images

1. Simply drag and drop your images into this folder
2. Make sure the filenames match exactly (case-sensitive)
3. Supported formats: JPG, PNG, WebP
4. The website will automatically update when you replace the placeholder files

## Image Optimization Tips

- Use high-quality images but optimize them for web (compress without losing quality)
- Recommended dimensions for project images: 1200x675px (16:9 aspect ratio)
- Recommended dimensions for profile photo: 800x800px or higher
- Tools for optimization: TinyPNG, ImageOptim, or Squoosh
