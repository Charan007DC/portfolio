## Image Specifications

- **Format**: JPG, PNG, or WebP (WebP recommended for best performance)
- **Dimensions**: 1200x800px (3:2 aspect ratio)
- **File Size**: Under 500KB each
- **Quality**: 80-85% compression

## Tips for Great Screenshots

1. **Show the UI in action** - Capture your project during actual use
2. **Clean background** - Ensure screenshots are professional
3. **Highlight key features** - Show what makes your project unique
4. **Good lighting/contrast** - Ensure text and UI elements are visible
5. **Consider mockups** - Use device mockups for better presentation

## Tools for Image Optimization

- **TinyPNG**: https://tinypng.com

- **ImageOptim**: https://imageoptim.com
