## 🚀 Quick Start (5 minutes)

### 1. Install & Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

### 2. Must Update Before Deploying

1. **Contact Information** → `components/Contact.tsx`
   - Replace: email, LinkedIn, GitHub, location

2. **Social Links** → `components/Footer.tsx`
   - Update: GitHub, LinkedIn URLs

3. **Resume** → Add `public/resume.pdf`
   - Update links in `Hero.tsx` and `Contact.tsx`

4. **Project Images** → Add to `public/projects/`
   - `legal-ai.jpg`
   - `havenpath.jpg`
   - `f1-agent.jpg`

5. **Project Links** → `components/Projects.tsx`
   - Update: GitHub and demo URLs
